# E-Commerce Sales & Customer Performance Analysis

## Project Overview
This project analyzes e-commerce sales data using MySQL to understand sales performance, customer purchasing behavior, product performance, and order trends.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- Customers
- Products
- Orders
- Order Details

## Project Objectives
- Analyze total sales revenue.
- Understand customer purchasing behavior.
- Identify top-selling products.
- Analyze city-wise and state-wise sales.
- Identify repeat and high-value customers.
- Analyze order statuses.
- Provide business recommendations based on data.

## SQL Skills Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- Aggregate Functions
- HAVING
- CASE
- RANK
- Subqueries

## Project Outcome
The analysis helps businesses understand sales trends, identify valuable customers, recognize top-performing products, and make data-driven business decisions.
