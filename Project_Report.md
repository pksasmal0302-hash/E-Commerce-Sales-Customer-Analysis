# E-Commerce Sales & Customer Performance Analysis

## 1. Project Overview
This project focuses on analyzing e-commerce sales and customer data using MySQL. The main purpose is to understand sales performance, customer behavior, product performance, and order trends.

## 2. Business Problem
An e-commerce business needs to understand:
- How much revenue is generated?
- Which products are selling the most?
- Which customers are valuable?
- Which cities and states generate more sales?
- How many orders are delivered, pending, and cancelled?

## 3. Project Objectives
- Calculate total sales revenue.
- Analyze total orders, customers, and products.
- Perform monthly sales analysis.
- Analyze city-wise and state-wise sales.
- Identify top-selling products.
- Identify repeat and high-value customers.
- Analyze product and category performance.
- Provide business recommendations.

## 4. Tools and Technologies
- MySQL
- MySQL Workbench
- SQL
- Visual Studio Code

## 5. Database Structure
The project contains four tables:

1. Customers – Stores customer information.
2. Products – Stores product information.
3. Orders – Stores order information and status.
4. Order Details – Stores product quantities and prices for each order.

## 6. SQL Concepts Used
- SELECT
- COUNT()
- SUM()
- AVG()
- WHERE
- GROUP BY
- ORDER BY
- INNER JOIN
- HAVING
- CASE
- RANK()
- LIMIT

## 7. Analysis Performed
A total of 20 SQL analysis questions were prepared to analyze:
- Total revenue and average order value.
- Monthly sales performance.
- City-wise and state-wise sales.
- Order status distribution.
- Delivered order revenue.
- Top-selling and low-performing products.
- Customer purchase behavior.
- Customer spending categories.
- Product revenue ranking.

## 8. Business Recommendations
- Maintain sufficient stock of best-selling products.
- Offer promotions on low-performing products.
- Reward high-value and repeat customers.
- Improve the order delivery process.
- Investigate reasons for cancelled orders.
- Focus marketing on high-revenue product categories.

## 9. Project Conclusion
This project demonstrates how SQL can be used to analyze e-commerce data and generate meaningful business insights. The analysis supports better understanding of customer behavior, sales trends, and product performance.

## 10. Project Status
SQL database creation, sample data insertion, and 20 SQL analysis questions have been completed.
